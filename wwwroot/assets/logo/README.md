## Logo assets for backend emails / static content

- Place your logo image files in this folder, for example:
  - `logo-email.png`
  - `logo-dashboard.png`

### How URLs will look in development

- Base URL (the backend): `http://localhost:5099`
- Static files are served from `wwwroot`, so a file at:
  - `wwwroot/assets/logo/logo-email.png`
- Sẽ truy cập được qua:
  - `http://localhost:5099/assets/logo/logo-email.png`

You can use this URL directly in email templates (OTP, verification, etc.).
